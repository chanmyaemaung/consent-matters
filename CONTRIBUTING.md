# Contributing

Thanks for your interest in Consent Matters!

## How this project works

Active development happens in a **private repository**. This public
repository carries **production releases only** — so there is no
development history here, and pull requests can't be accepted directly.

That said, contributions absolutely shape the app:

- 💡 **Feature requests** — open an [issue](../../issues) describing
  what you need and why. Merchant stories are the best input.
- 🐛 **Bug reports** — open an issue with steps to reproduce, your
  theme name, and a storefront URL if possible.
- ✉️ Merchants can also reach support from inside the app.

Every release is reviewed, typechecked, linted, and end-to-end tested
before it lands here.

## Code of conduct

Be kind. Merchants, shoppers, and developers all deserve respect.
